# AmanGuard Family — الرقابة الأبوية (المرحلة 1)

تطبيقان أصليان (Kotlin + Compose) وخادم Firebase:
- `parent/` تطبيق ولي الأمر · `child/` تطبيق الطفل · `core/` الصلاحيات والواجهات المشتركة
- `functions/` Cloud Functions (TypeScript) · `firestore.rules` قواعد الأمان

## ما الذي يعمل في هذا الإصدار
الحسابات، ربط الجهاز برمز مؤقت/QR، معالج الصلاحيات وشاشة الحالة وإعادة الفحص، نبضة الاتصال، الموقع الدوري والأمر الفوري، المناطق الجغرافية (على الخادم)، تقرير استخدام التطبيقات، قائمة التطبيقات، الأوامر بنتيجة فعلية، تنبيهات FCM، إلغاء الربط، الاحتفاظ بالبيانات.

## ما لا يعمل بعد (بصراحة)
حظر التطبيقات وتنفيذ وقت الشاشة، مزامنة الإشعارات، حماية الويب، الكلمات المفتاحية، عرض الشاشة/الكاميرا/الصوت المحيط، الاشتراكات، iOS. التفاصيل في `docs/FEATURE_STATUS_AR.md`.

## التشغيل
1. أنشئ مشروع Firebase واتبع `docs/SETUP_FIREBASE_AR.md`.
2. ارفع المجلد إلى GitHub وأضف الأسرار المذكورة في `docs/DEPLOYMENT_AR.md`.
3. شغّل Workflow «Build AmanGuard» ونزّل APK من Artifacts.

> لم يُبنَ هذا الكود ولم يُختبر على جهاز في بيئة الإنشاء (لا إنترنت ولا Android SDK). قد يُظهر أول بناء على GitHub أخطاء ترجمة صغيرة؛ أرسلها لي لإصلاحها.
