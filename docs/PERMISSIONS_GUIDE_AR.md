# دليل الصلاحيات

| الصلاحية | الوظيفة | طريقة التفعيل | ملاحظة |
|---|---|---|---|
| الإشعارات | التنبيهات + إشعار المزامنة | نافذة (Android 13+) / إعدادات | طفل وولي أمر |
| الموقع الدقيق | الموقع والسجل | نافذة النظام | التقريبي وحده = «مفعلة جزئيًا» |
| مفتاح الموقع | كل وظائف الموقع | إعدادات الموقع | يُفحص بشكل مستقل |
| الموقع في الخلفية | تحديث دوري | Android 11+: صفحة الإعدادات «طوال الوقت» | لا يُطلب قبل الدقيق |
| إحصاءات الاستخدام | تقارير الاستخدام | صفحة خاصة | لا تُرفع بيانات استخدام بدونها |
| البطارية دون قيود | موثوقية الخلفية | صفحة إعدادات البطارية | إرشادي؛ بعض الشركات تحتاج «التشغيل التلقائي» يدويًا |

- كل حالة تُفحص فعليًا ولا تُعرض «ممنوحة» إلا بعد نجاح الفحص.
- إعادة الفحص: عند فتح التطبيق/العودة من الإعدادات (ON_RESUME) وقبل كل مهمة وفي كل نبضة اتصال.
- الإلغاء بعد المنح يظهر «أُلغيت»، ويُرسل تنبيه لولي الأمر (دالة `onPermissionsWritten`).
- ولي الأمر يرى الحالة فقط؛ لا يستطيع منح الصلاحية عن بُعد.
- لم تُعلن في Manifest: الكاميرا، الميكروفون، مستمع الإشعارات، Accessibility، VPN، Device Admin (لأن وظائفها غير منفذة بعد).
