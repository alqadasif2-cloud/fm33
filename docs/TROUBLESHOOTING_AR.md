# استكشاف الأخطاء

- **فشل البناء: google-services.json مفقود** ← أضف الأسرار (DEPLOYMENT_AR).
- **الخريطة رمادية** ← مفتاح الخرائط غير مضاف أو غير مقيّد بالحزمة الصحيحة.
- **Callable يرجع unauthenticated/failed-precondition** ← فعّل Anonymous Auth؛ وإن فعّلت الإلزام فسجّل رمز App Check التجريبي.
- **الأمر «فشل: لا يوجد رمز دفع»** ← افتح تطبيق الطفل مرة واحدة بعد الربط.
- **الموقع لا يصل** ← افتح «حالة الصلاحيات» على الطفل: يلزم الدقيق + مفتاح الموقع + «طوال الوقت».
- **الموقع متأخر** ← قيود البطارية: اسمح بالعمل دون قيود وفعّل التشغيل التلقائي (dontkillmyapp.com).
- **استخدام التطبيقات فارغ** ← إذن الوصول إلى الاستخدام غير ممنوح.
- **Firestore: PERMISSION_DENIED** ← الجهاز أُلغي ربطه أو القواعد لم تُنشر.
- **طلب فهرس مفقود** ← `firebase deploy --only firestore:indexes`.
